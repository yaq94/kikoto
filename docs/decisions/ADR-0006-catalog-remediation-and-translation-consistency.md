# ADR-0006：目录整改、译文覆盖与个人恢复的一致性

## Status

Accepted. Amends ADR-0007's source-field cache retention clause.

## Context

`ADR-0004` 规定无码对象身份与个人记录边界。整改工作包 D-16、D-17、D-22、D-27、D-29 及翻译工作包进一步约束目录、译文与清理，但其中的旧删除计划、固定短查询窗口与全量覆盖目标存在冲突。

## Decision

1. 目录准入统一采用 D-16 三项拒绝条件：无音频拒绝；文件总数大于 5,000 拒绝；非音频大于 2,000 且音频少于 5 拒绝；等于阈值允许。限制按每个来源目录／卡片根计算，系列卡片不聚合文件数，每个成员条目分别判定；未通过成员不进入系列卡或详情，不影响其他合格成员，系列至少有一个合格成员才显示。入队、发布和 API 不各自放宽规则。partial 仅限制未知范围，不能冻结已成功范围的后续增量。每日 03:00 执行目录优先增量，周日 03:00 全量对账，时区为 Asia/Shanghai；两者同时到期只创建一个全量任务。
2. 显示语言搜索严格使用目标语言译文或原生内容；`origin` 才查询原文，不做原文回退，不提供覆盖率提示。发行编号、精确代码等结构化查询不受显示语言过滤。有界搜索通过完整有效集合的索引或逐段处理实现，不设置会遗漏旧内容的固定结果窗口；`zh-tw` 查询先做 t2s 归一化，并同时考虑 `zh-Hans` 与原生 `zh-Hant` 行。
3. 有效译文覆盖以当前可用 entry、series、work、当前原文、当前模型、base URL、模板和 reasoning 配置判定。当前行必须匹配 `config_key`（native 行除外），覆盖统计不能用历史行 `count(*)`。`complete` 表示该定义下无缺失、无 stale、无失败重试，不表示一次游标扫描结束；连续失败跳过、历史行、superseded、退役条目和旧配置行都不计入覆盖。`cacheBytes` 作为软预算信号，不删除仍需提供持久搜索的当前标题译文；可重建的非标题显示缓存和 `source_field_translation` 可以淘汰，但不得成为搜索正确性的依赖。
4. 个人备份使用稳定引用表达单集的父级归属。`work.parent_work_id`（或等价的单父系列关系表）只保存备份明确给出的必要身份与关系；一个单集只能有一个明确父系列，多个来源给出不同父系列时报告 `parent_conflict`，不猜测。恢复不根据标题猜测关联，不覆盖既有共享关系或他人记录。无法解析或冲突的父级必须报告并保留可审阅状态，不能静默降级为独立单集。
5. 废止整改补充 D-17 中删除仍承担个人稳定引用的 `personal_transfer_ref` 的计划。保留 source-only alias，直到其个人引用有明确、可审阅的归属。旧 dry-run 只能作历史记录，不能指导当前清理。D-17 对 entry/file/observation/directory/audio_root 的删除只适用于没有个人引用且不属于 series/alias 的卡片；不得把“删除 transfer ref”重新引入。

## Consequences

- 覆盖、调度和清理均须有可复核的实际状态，失败或资源暂停不显示为完整。
- 翻译存储的容量控制通过有效集合清理、显式软告警及可重建缓存处理，不能以牺牲已承诺的搜索覆盖换取指标。
- 095 已被修改过，已执行旧 095 的数据库必须在 096 之后通过 097 修复，并在迁移入口处理旧 checksum；096 未提交前不得写 097。
- 本决定补充 `ADR-0004`，并修正 `ADR-0007` 的来源字段缓存保留条款；不改变其用户隔离、本人确认、作品身份及不隐式下载媒体的约束。
