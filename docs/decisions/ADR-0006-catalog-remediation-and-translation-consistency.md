# ADR-0006：目录整改、译文覆盖与个人恢复的一致性

## Status

Accepted.

## Context

`ADR-0004` 规定无码对象身份与个人记录边界。整改工作包 D-16、D-17、D-22、D-27、D-29 及翻译工作包进一步约束目录、译文与清理，但其中的旧删除计划、固定短查询窗口与全量覆盖目标存在冲突。

## Decision

1. 目录准入统一采用 D-16 三项拒绝条件；入队、发布和 API 不各自放宽规则。partial 仅限制未知范围，不能冻结已成功范围的后续增量。每日 03:00 执行目录优先增量，周日 03:00 全量对账，时区为 Asia/Shanghai。
2. 显示语言搜索严格使用目标语言译文或原生内容；`origin` 才查询原文。有界搜索通过完整有效集合的索引或逐段处理实现，不设置会遗漏旧内容的固定结果窗口。
3. 有效译文覆盖以当前可用条目、原文、模型和模板判定。`complete` 表示该定义下无缺失，不表示一次游标扫描结束。`cacheBytes` 作为软预算信号，不删除仍需提供持久搜索的当前译文；可淘汰缓存不得成为搜索正确性的依赖。
4. 个人备份使用稳定引用表达单集的父级归属。恢复仅重建备份明确给出的必要身份与关系，不根据标题猜测关联，不覆盖既有共享关系或他人记录。
5. 废止整改补充 D-17 中删除仍承担个人稳定引用的 `personal_transfer_ref` 的计划。保留 source-only alias，直到其个人引用有明确、可审阅的归属。旧 dry-run 只能作历史记录，不能指导当前清理。

## Consequences

- 覆盖、调度和清理均须有可复核的实际状态，失败或资源暂停不显示为完整。
- 翻译存储的容量控制通过有效集合清理、显式软告警及可重建缓存处理，不能以牺牲已承诺的搜索覆盖换取指标。
- 本决定补充 `ADR-0004`，不改变其用户隔离、本人确认、作品身份及不隐式下载媒体的约束。
