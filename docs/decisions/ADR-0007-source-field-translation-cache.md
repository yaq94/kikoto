# ADR-0007: Source Field Translation Cache

## Status

Accepted. The retention clause is amended by ADR-0006.

## Context

Remote titles, tags and directory display names can be requested without a
registered `work`, `catalog_entry` or `catalog_series` identity. Searchable
translations use `content_translation`, whose rows are tied to those durable
entities and indexed for content search. Reusing that table for free-form source
fields would either require an unstable synthetic entity id or mix display
cache into the search corpus.

## Decision

Store successful model results for source-level fields in
`source_field_translation`. A row is keyed by source, work code, field, real
relative path, source text, target language, model, endpoint, reasoning switch
and template version.

The table is display cache, not search corpus. It has no FTS table or trigger,
and content search never reads it. Only non-empty model output is stored.
Source availability and the exact public field are revalidated before a cached
row is considered.

Rows are rebuildable display cache. The existing `maxEntries` and `cacheBytes`
maintenance pass counts and evicts `source_field_translation` rows and
non-title `content_translation` model rows. Searchable title rows in
`content_translation` are durable corpus and are never eviction candidates;
see ADR-0006. Native authored rows, personal records and source identities are
never eviction candidates.

## Consequences

- Repeated views across sessions and restarts reuse the same source-field
  translation without making it searchable content.
- The published `content_translation` entity constraint is unchanged. Its row
  shape gains a `config_key` so a model row is current only for the model, base
  URL, template version and reasoning switch that produced it; the independent
  display cache remains in `source_field_translation`.
- Cache budget accounting covers two tables but keeps one bounded eviction
  policy and one maintenance path; ADR-0006 separates persistent search titles
  from rebuildable display cache.
- Model-generated Traditional Chinese reuses the Simplified row and converts at
  display time. Source text detected as Traditional is stored once as a native
  `zh-Hant` row and is never regenerated by the model.
