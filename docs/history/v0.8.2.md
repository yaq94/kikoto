> [!IMPORTANT]
> **Upgrade notes.** Back up `config/` before upgrading and keep the existing
> `data/` mount. This release keeps schema 066: v0.8.1 databases need no new
> migration, and fresh installs reuse `baseline/066_v0.8.1.sql`. Older databases
> continue through the numbered migration chain; do not replace an existing
> database with a fresh-install baseline.
>
> **Fetch and Availability Watch permissions.** Fetch workflows, including
> bulk Fetch and Fetch-based popular collections, require both `remote:fetch`
> and `metadata:sync`. Availability Watch always requires `metadata:sync`,
> plus the remote permissions for its selected action. Contributor accounts
> cannot run or automate these paths; use an Admin account for them.
> Contributors keep Track, Fork, untracking, source checks for a work, and
> remote-file caching.
>
> **Custom production Compose files.** If your Compose file drops every
> capability with `cap_drop: ALL`, copy `cap_add: [DAC_OVERRIDE]` from the
> bundled production Compose file so mounted folders owned by another host
> user remain writable and readable. The Demo Compose file is unchanged.
>
> **Android 12 and earlier.** Enabling **Hide content in recent apps** also
> blocks screenshots, screen recording, and casting on these versions.
> Android 13 and later keep this choice limited to the task preview.

> [!NOTE]
> Use `docker compose up -d --pull always` to upgrade the production stack;
> restarting a container reuses its installed image. Update `KIKOTO_IMAGE`
> first if it is pinned to an older release. Update the native app as well
> to receive the preview and device-privacy fixes.

Kikoto v0.8.2 refreshes the phone Library, adds optional compact cards, and
fixes native remote previews, large temporary files, and mounted-folder
permissions. It also improves circle browsing, source-dependent automation,
and remote-action permission enforcement.

<details>
<summary><strong>Library and work detail</strong></summary>

- The phone Library keeps search visible, places sources and Quick mark
  filters in chip rows, and labels the sort button with the current order.
  The sort popover contains both the order and direction choices.
- A result-count and current-page caption replaces the top pager on phones;
  the bottom pager is unchanged.
- A **Continue listening** strip shows recently played works and their
  progress. It starts collapsed and replaces the history button on phones.
- **Compact cards** in display options is off by default. One column shows
  rows with the cover beside the facts; two columns show short tiles. The
  option applies to Local, Tracked, and remote sources. Desktop layouts are
  unchanged.
- Circle catalog works are paginated on the server, with complete totals and
  search, availability, and series filters applied before pagination. Bulk
  selection covers the loaded page.

</details>

<details>
<summary><strong>Sources and remote fetch</strong></summary>

- Android and iOS attach the session credential to remote preview assets,
  including media, text, and proxied images, so signed-in previews work when
  the server requires authentication.
- Fetch planning checks the download-size limit before creating a review or
  queueing a transfer.
- Fetch-based workflows and Availability Watch enforce the permissions of
  their metadata and remote steps in both the API and the UI.
- Disabling or removing a remote source automatically pauses the workflow
  triggers that depend on it, preserving their schedule and options. The
  scheduler also checks source availability before dispatch. Re-enabling a
  source leaves its paused triggers for an administrator to review and enable.

</details>

<details>
<summary><strong>Operations and reliability</strong></summary>

- Large temporary files use `.kikoto-tmp` inside the cache root rather than
  the system temporary directory, which the bundled Compose stacks bound to
  a 64 MiB `/tmp`. Database compaction and large Kikoeru database uploads
  therefore avoid that small temporary-space limit.
- Compaction needs free space on the cache volume of about the database size.
  Startup empties `.kikoto-tmp`; if the directory cannot be prepared, the
  server logs a warning and falls back to the system temporary directory.
- Production Compose adds back `DAC_OVERRIDE` so deleting, Fetch, and scans
  work on mounted media folders that belong to another Linux host user.
- API responses hide local source paths and cache paths from accounts that
  do not manage sources.
- Android 12 and earlier keep Kikoto content out of recent-task previews in
  split-screen and freeform windows when **Hide content in recent apps** is
  enabled.

</details>

<details>
<summary><strong>Development and docs</strong></summary>

- Frontend API clients are separated by domain over a shared transport. The
  Library route separates its controller, loaders, and panels, and backend
  circle, voice, and workflow handlers are split by responsibility.
- TypeScript is updated to 7.0.2, Oxlint replaces ESLint, and frontend
  dependencies are refreshed.
- The About page links recommendation references, and GitHub automation
  labels issues and pull requests.

</details>
