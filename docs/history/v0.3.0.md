Kikoto v0.3.0 expands library browsing, remote-source workflows, playback
continuity, and the read-only Demo experience while making background work more
predictable and observable.

<details>
<summary><strong>Library And Work Detail</strong></summary>

- Added adaptive shared collection layouts and refined Library, Favorites,
  Circle, and voice-actor browsing across desktop and mobile.
- Improved language-edition grouping, remote translation discovery, work cards,
  sorting, recommendations, and progressive detail rendering.
- Unified source previews, remote directory state, and playback behavior without
  creating separate work identities for alternate locations or editions.

</details>

<details>
<summary><strong>Sources And Remote Fetch</strong></summary>

- Queued remote Track operations, deduplicated concurrent Fetch runs, and added
  completion notifications and clearer maintenance controls.
- Improved source provenance, origin metadata, availability watches, request
  pacing, and remote browse recovery.
- Kept remote playback, cache state, Track presence, and durable Fetch
  publication distinct throughout the UI and backend workflows.

</details>

<details>
<summary><strong>Workflows And Maintenance</strong></summary>

- Added configurable built-in triggers and native filesystem-triggered local
  scans, with startup refresh folded into the same scan workflow.
- Added durable job priorities, resource-aware scheduling, asynchronous system
  runs, source throttling, and shared popular-collection tag templates.
- Refined workflow composition, review, maintenance, cache, and source-management
  layouts for denser and more consistent operation.

</details>

<details>
<summary><strong>Playback And Client State</strong></summary>

- Added video playback support and improved media refresh, queue restoration,
  compact playback, and source fallback behavior.
- Moved Resume progress to a canonical work-scoped cursor so editions and tracks
  do not create competing persisted playback positions.
- Scoped account-bearing browser state by server and user while preserving
  device-level display preferences.

</details>

<details>
<summary><strong>Demo, Security, And Reliability</strong></summary>

- Expanded the isolated read-only Demo runtime with admitted metadata, covers,
  media, and sanitized administration and workflow views.
- Added public security reporting, privacy, design, and outbound-request
  hardening guidance without claiming unimplemented transport protections.
- Prevented persistent SQLite writer locks and strengthened frontend regression
  coverage for responsive collection layouts.

</details>
