# 统一作品拥有个人记录，无码作品采用有条件的自动关联

用户选择让同一作品跨源共享个人评分与备注。保存远端作品的个人记录可以登记必要作品信息并使其出现在作品库列表，但不触发媒体下载。这样保留统一作品的概念，也允许复用现有个人记录结构，避免随来源切换产生多份互相矛盾的评价。

接入范围包含匿名可访问且可直接播放的无发行编号音声，因此发行编号不能继续作为作品准入的唯一条件。已有编号与可靠作品关系优先；无编号条目依据标题、声优等多项证据，仅对高置信且唯一的候选自动关联。证据不足、多个候选或信息矛盾时分别展示并提供确认入口。这选择保留自动整理能力，同时接受部分重复条目，以降低误关联个人记录与媒体的风险。

自动关联仍受个人记录冲突约束：同一用户在两条作品上已有不同评分或备注时，保留两份记录并暂停合并，待记录本人确认评分和备注后完成关联，不自动覆盖或拼接。不同用户的评价差异不构成此类冲突。这让统一个人记录的目标服从本人对已有评价的确认。

无码音声按系列展示一张卡片，内部列出单集；系列和每个单集分别拥有当前用户的评分与备注。自动归组以明确系列名、集数或系列目录为证据；其余内容独立展示，由用户确认是否归组。系列归组保留各集的独立身份，同一系列或同一单集的记录各自在不同来源间共享。这需要保留系列与单集两个评价层级，避免把展示归组误当成作品去重而覆盖各集记录。

误关联拆分时，合并后新增或修改的评分、备注由记录本人在拆分预览中选择归属，也可选择两边保留。系统不得自动替本人决定或丢弃记录；纠正作品关联必须保留本人对合并后个人记录的处置权。

人工系列归组、作品关联和拆分属于全库共用资料，沿用现有资料编辑权限。个人评分与备注保持私有，任何冲突只由记录本人处理，不向其他用户暴露记录。共享资料编辑权不包含代替他人决定个人记录归属的权限。

本决定明确需求边界，不宣称实现完成。稳定身份、匹配细则及共享操作完成条件的建议实现方案见 [规格](../../.scratch/kikoto-next/spec.md)，随整体设计确认；作品关联不能直接推导不同版本的音轨可无缝互换。
