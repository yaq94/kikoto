# 10: 来源目录改名、失联、删除与恢复

**What to build:** 来源变化时仍能找到卡片与个人记录；可靠改名更新定位，失联、确认缺失和恢复分别显示，并支持受权限约束的清理。

## 验收清单

- [x] 只有稳定标识或可靠来源证据证明唯一同一对象时更新改名/移动定位；否则保留原对象与评价，显示待确认候选。
- [x] 失败、维护、访问限制、待确认空目录与成功完整扫描后的缺失分别处理；未完成扫描不能确认永久删除。
- [x] 单源失败不改变其他来源状态；全源确认删除仍保留卡片和记录，重新可用后恢复。
- [x] 手动清理校验资料权限；仍有个人记录引用时延后共享对象物理删除，不能级联删除他人评价。
- [x] 跨连续扫描和重启验证身份、来源状态与记录保留；未确认候选不能冒充已认回或自动转移记录。

## 测试与交付边界

**测试入口:** H、R；来源状态与清理提示按需要复用 F。

H 使用真实 HTTP、会话和迁移 SQLite；R 真实关闭并重启同一应用及同一测试库；F 仅复用少量 Playwright 纯功能用例，关闭本期截图采集，不做像素、布局或人工视觉验收。
