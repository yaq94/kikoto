# 03: 简繁转换与受保护名称保持

**What to build:** 用户选择繁体中文时，系统取得或复用简体译文，再通过成熟转换规则呈现繁体，保留查看原文和失败状态。

**Blocked by:** [02：浏览内容翻译、原文与有界缓存](02-content-translation-cache.md)

**Status:** ready-for-agent

**依据:** [正式规格](../spec.md) · [工单总览](../ticket-proposal.md)

## 验收范围

**主责:** AC-07

**共同:** AC-04、AC-06、AC-28

在 02 已实现的保护文字和缓存边界上补齐繁体路线。

## 验收清单

- [ ] 同一原文在简繁之间切换时复用匹配简体译文，不重复生成；简繁显示和缓存不会混用。
- [ ] 转换保持受保护名称、个人文字、真实路径和对象身份；转换失败返回原文与可理解状态。
- [ ] 使用成熟简繁转换实现；新增依赖须说明用途、版本并遵守安装授权，不自行编写大型转换字典。
- [ ] 固定样例验证文本结果和请求次数，有限真实文本样例检查翻译与转换语义；迟到结果仍遵守当前语言选择。

## 测试与交付边界

**测试入口:** H、F；文本语义质量补 LIVE，无浏览器视觉签收。

H 使用真实 HTTP 路由、会话与迁移 SQLite；F 仅运行少量纯功能用例，关闭截图采集，不做截图、像素、布局或人工视觉验收；LIVE 仅在显式配置的隔离环境有限执行。

遵守工单总览的[共同完成要求](../ticket-proposal.md#共同完成要求)，复用既有测试入口；不新增测试技术栈或安装授权。
