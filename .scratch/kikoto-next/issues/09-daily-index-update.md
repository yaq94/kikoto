## 验收清单

- [x] 首次完整索引完成前不误启动独立每日全站任务；完成后每日触发更新。
- [x] 运行中、暂停或待恢复的同源扫描被复用或续跑；反复手动刷新和重启不会产生重叠全站任务。
- [x] 手动与定时更新遵守相同权限、检查点、限速、取消和低空间规则。
- [x] 新内容随扫描推进可检索；调度触发、局部成功或经过一天均不能显示为全站扫描完成。
