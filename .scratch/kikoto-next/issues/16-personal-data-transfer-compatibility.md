# 16: 编号、无码、系列与单集个人数据导入导出

**What to build:** 用户导出并恢复所有新增评价对象上的本人记录，兼容旧编号格式；空库往返及重复导入不遗漏、不重复、不静默覆盖。

**Blocked by:** [12：系列与单集独立个人评价](12-series-episode-personal-reviews.md)。

**Status:** ready-for-agent

**依据:** [正式规格](../spec.md) · [工单总览](../ticket-proposal.md)

## 验收范围

**主责:** AC-24。

**共同:** AC-09、AC-13。

导入本人字段冲突独立于共享关联流程；本票不通过导入重写全库关系。

## 验收清单

- [ ] 新格式表达编号作品、无码作品、系列与单集的必要稳定身份及本人记录，不静默跳过新对象。
- [ ] 旧有效编号格式仍可导入；导出后在空库恢复，评分备注和评价对象归属一致。
- [ ] 重复导入不产生重复对象；存在不一致记录时保留信息并给本人可审阅结果，不静默覆盖。
- [ ] 译名或临时媒体链接不替代稳定身份；仅处理本人私有数据，不泄露他人记录、不越权改变共享关系、不下载音频。

## 测试与交付边界

**测试入口:** H、R，使用新旧合成格式、空库往返、重复导入和冲突样例。

H 使用真实 HTTP、会话和迁移 SQLite；R 真实关闭并重启同一应用及同一测试库。

共用规则见总览的[共同完成要求](../ticket-proposal.md#共同完成要求)。本票实施完成时，验收证据必须对应实际产物，同步相关文档并提交、推送 Git。工单发布不代表功能实施或生产授权。
