## 验收清单

- [x] 新格式表达编号作品、无码作品、系列与单集的必要稳定身份及本人记录，不静默跳过新对象。
- [x] 旧有效编号格式仍可导入；导出后在空库恢复，评分备注和评价对象归属一致。
- [x] 重复导入不产生重复对象；存在不一致记录时保留信息并给本人可审阅结果，不静默覆盖。
- [x] 译名或临时媒体链接不替代稳定身份；仅处理本人私有数据，不泄露他人记录、不越权改变共享关系、不下载音频。
