# 07: 有限 OpenList 入口贯通无码卡片、目录、播放与评价

**What to build:** 从一个明确限定范围的匿名 OpenList 来源树发现编号和无码音声，在统一搜索和卡片中打开目录、点选音轨播放，并保存个人评价。

**Blocked by:** [04：编号作品全源个人评分与备注](04-numbered-work-personal-reviews.md)；[06：稳定内部引用与编号兼容入口](06-stable-identity-compatibility.md)

**Status:** ready-for-agent
**Implementation:** resolved

**依据:** [正式规格](../spec.md) · [工单总览](../ticket-proposal.md)

## 验收范围

**主责:** AC-08、AC-09、AC-12

**共同:** AC-13、AC-25、AC-27、AC-28

AC-08 的有限集合、AC-09 的无码身份、AC-12 的无码评价；全量遍历由 08 负责。

## 验收清单

- [x] 一个有编号、一个无码、一个排除目录构成最小样例；未登记条目也可搜索、显示卡片和浏览目录。
- [x] 无码身份跨重启稳定，不伪造发行编号；格式及分轨属于正确作品，纯压缩包或纯字幕目录不显示为可播放作品。
- [x] 保存个人记录按需登记必要信息并遵守当前用户权限，不触发媒体下载或持久音频镜像。
- [x] 显示名、来源路径与临时媒体链接分别处理；链接过期能重新取址，选中音轨对应正确来源文件。
- [x] 对有限真实匿名媒体验证实际范围读取与指定偏移；不把目录/get 成功、合成 WAV 或健康检查当成真实源播放证明。
- [x] 元数据请求遵守并发、速率、响应大小和取消边界；本票新增来源出站路径自行完成 AC-27。
- [x] 有限样例只证明本票链路，不宣称全站索引或多源播放切换完成；后者分别由 08、05 验收。

## 测试与交付边界

**测试入口:** H、R；有限完整用户链路补 F；匿名媒体 Range 与定位读取补 LIVE。

H 使用真实 HTTP 路由、会话与迁移 SQLite；R 实际关闭并重启同一应用；F 仅运行少量纯功能用例，关闭截图采集，不做截图、像素、布局或人工视觉验收；LIVE 仅在显式配置的隔离环境有限执行。

遵守工单总览的[共同完成要求](../ticket-proposal.md#共同完成要求)，复用既有测试入口；不新增测试技术栈或安装授权。

本票验收证据须对应实际产物，相关文档同步并提交、推送 Git。工单发布不代表功能实施或生产授权。
