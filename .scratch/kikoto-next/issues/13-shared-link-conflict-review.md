# 13: 共享关联、归组预览与本人冲突确认

**What to build:** 资料编辑者发起共享关联或涉及评价对象合并的归组，各受影响用户处理自己的冲突；全部必要确认完成后统一提交。

**Blocked by:** [12：系列与单集独立个人评价](12-series-episode-personal-reviews.md)。

**Status:** resolved

**Implementation:** resolved；本地实现与 H/F 已验收；生产部署验收见 17。

**证据:** [实现边界与验收](../evidence/13-shared-association.md)

**依据:** [正式规格](../spec.md) · [工单总览](../ticket-proposal.md)

## 验收范围

**主责:** AC-16、AC-18。

**共同:** AC-13、AC-14、AC-15、AC-28。

覆盖作品、系列与单集的适用同层级关联；保持系列成员及版本边界。

## 验收清单

- [x] 预览展示对象与来源归属及当前用户可处理的记录；系列、单集与版本仍有独立身份，不把跨层级归组当作作品去重。
- [x] 按同一用户在两对象上的同一字段识别冲突，保留不同已填写值；空值不覆盖已有内容，不同用户评价不同不构成冲突。
- [x] 以资料编辑者和两名有冲突的普通用户验收：本人无需资料编辑权即可确认，编辑者不能代替；仅一人确认时仍待处理且原关系、记录保留。
- [x] 最后一项必要确认后关联及记录归属一致提交；其他用户的预览、状态与结果不返回他人评分备注。
- [x] 相关数据变更后拒绝过期预览；中途重启可继续本人选择，不出现部分关联或记录丢失。
- [x] 保留关联前依据供拆分使用；沿用已有共享资料权限、个人状态和持久任务机制。

## 测试与交付边界

**测试入口:** H、R；本人确认、权限和过期预览的关键操作复用 F。

H 使用真实 HTTP、会话和迁移 SQLite；R 真实关闭并重启同一应用及同一测试库；F 仅复用少量 Playwright 纯功能用例，关闭本期截图采集，不做像素、布局或人工视觉验收。

共用规则见总览的[共同完成要求](../ticket-proposal.md#共同完成要求)。本票实施完成时，验收证据必须对应实际产物，同步相关文档并提交、推送 Git。工单发布不代表功能实施或生产授权。
