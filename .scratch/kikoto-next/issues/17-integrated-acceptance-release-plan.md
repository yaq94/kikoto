## 验收清单

- [ ] 至少一条真实前后端链路贯通编号/无码浏览、翻译、目录、评价及必要共享操作；外部服务可以使用边界桩，不能全部拦截自有 API 后宣称前后端联通。
- [ ] 可用音轨播放时并行浏览、扫描和翻译并触发限额与低空间；音轨和队列保持、播放进度继续推进，后台失败或暂停不停止播放器。
- [ ] 记录请求速率、队列、缓存、内存和磁盘观察，按规格预算校准；既有读取和个人记录保留，暂停及失败可恢复。
- [ ] 以当前产物核实真实 Index 生成、繁体文本、匿名媒体 Range/定位读取与指定环境播放证据；明确数据规模、格式、浏览器及真实覆盖缺口。
- [ ] 验证迁移、任务恢复、待确认操作、来源恢复和个人数据传输的组合，核实测试库备份恢复与回退前提。
- [ ] 所有选定浏览器用例遵守非视觉边界，关闭本期截图采集，不进行布局、像素或人工视觉验收。
- [ ] 交付脱敏的产物版本、执行命令、退出状态和结果，以及部署与回退步骤；生产变更留给后续明确决定，本票不自动执行。

## 测试与交付边界

**测试入口:** H、R、少量 F、有限 LIVE；仅记录已经实际执行的覆盖。

H 使用真实 HTTP、会话和迁移 SQLite；R 真实关闭并重启同一应用及同一测试库；F 仅复用少量 Playwright 纯功能用例，关闭本期截图采集，不做像素、布局或人工视觉验收；LIVE 仅在显式配置的隔离环境有限执行。

共用规则见总览的[共同完成要求](../ticket-proposal.md#共同完成要求)。本票实施完成时，验收证据必须对应实际产物，同步相关文档并提交、推送 Git。工单发布不代表功能实施或生产授权。
