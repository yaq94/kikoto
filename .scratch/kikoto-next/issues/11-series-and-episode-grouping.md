# 11: 无码系列卡片与独立单集归组

**What to build:** 有明确系列证据的内容显示一张系列卡片，内部列出可独立打开目录的单集；证据不足时保持独立，并允许受权用户预览、确认归组。

**Blocked by:** [07：有限 OpenList 入口贯通无码卡片、目录、播放与评价](07-openlist-first-playable-slice.md)。

**开发先决条件:** 07 本地接口、069 迁移与 catalog 翻译已集成复验，可开始依赖这些接口的开发和受控测试；依据见[执行记录](../execution.md#开发依赖与发布依赖)。
**发布依赖:** 07 全部验收（含真实媒体 LIVE）和本票完整清单仍须通过；本地开发不关闭外部缺口，也不改变作品身份及个人记录保护要求。

**Status:** ready-for-agent
**Implementation:** resolved；本地实现与 H/F 已验收；生产部署验收见 17。
**本地证据:** [071、H/R/F 与回归验收](../evidence/11-series.md)。本票清单通过，07 真实媒体 LIVE 的发布依赖仍保留。

## 验收范围

**主责:** AC-14。

**共同:** AC-13、AC-18、AC-28。

AC-18 的非合并归组预览与持久化；涉及已有评价对象合并或记录冲突的操作由 13 扩充。

## 验收清单

- [x] 明确系列名、集数或系列目录证据才自动归组；仅创作者相同、标题相似或主题相近不足以归组。
- [x] 系列一张卡片列单集；格式副本和分轨归对应作品或单集，不产生额外作品、单集身份或卡片。
- [x] 人工归组校验资料编辑权限并提供预览，保存后其他用户可见；原单集身份、版本与个人记录保留。
- [x] 本票仅开放不会合并既有评价对象或搬迁个人记录的归组；需要冲突处置时保留原状，不能先执行再等待后续能力。
- [x] 从系列卡片到单集、来源目录与音轨的选择可操作；归组不把成员当作同一录音或时间轴。

## 测试与交付边界

**测试入口:** H、F；保存后共享与成员身份由公开查询回读。

H 使用真实 HTTP、会话和迁移 SQLite；F 仅复用少量 Playwright 纯功能用例，关闭本期截图采集，不做像素、布局或人工视觉验收。

共用规则见总览的[共同完成要求](../ticket-proposal.md#共同完成要求)。本票实施完成时，验收证据必须对应实际产物，同步相关文档并提交、推送 Git。工单发布不代表功能实施或生产授权。
