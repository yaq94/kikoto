# 01: 管理员翻译配置与 Index 试译

**What to build:** 管理员在设置中保存统一翻译接口、密钥和实际模型调用名，重新打开或重启后可试译并判断结果；普通用户使用该服务但不能取得密钥或修改配置。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**依据:** [正式规格](../spec.md) · [工单总览](../ticket-proposal.md)

## 验收范围

**主责:** AC-01、AC-02

**共同:** AC-27、AC-28

配置、持久化、权限、真实试译与失败状态。

## 验收清单

- [ ] 默认配置指向用户选定的 Index-Translate-35B-A3B，实际调用名可自行配置，不把权重仓库名或展示名强制写入请求。
- [ ] 保存、重新读取、重启后的配置一致；密钥仅供服务端使用，读回掩码；越权读取或修改被拒绝。
- [ ] 试译使用实际配置与约定的单条 user 模板；空输出、截断、格式错误、鉴权失败、限流和超时均有明确结果，不伪报成功或循环重发。
- [ ] 在显式配置的隔离环境完成有限真实生成，核实所选模型和接口参数；健康检查不能代替该证据。
- [ ] 本票新增出站路径自行验证目的地、重定向、凭据、响应大小、取消和错误隐藏规则；沿用已有组件和传输机制。

## 测试与交付边界

**测试入口:** H、R；配置表单复用 F；实际模型生成补 LIVE。

H 使用真实 HTTP 路由、会话与迁移 SQLite；R 实际关闭并重启同一应用；F 仅运行少量纯功能用例，关闭截图采集，不做截图、像素、布局或人工视觉验收；LIVE 仅在显式配置的隔离环境有限执行。

遵守工单总览的[共同完成要求](../ticket-proposal.md#共同完成要求)，复用既有测试入口；不新增测试技术栈或安装授权。

本票验收证据须对应实际产物，相关文档同步并提交、推送 Git。工单发布不代表功能实施或生产授权。
