**Blocked by:** [07：有限 OpenList 入口贯通无码卡片、目录、播放与评价](07-openlist-first-playable-slice.md)

**开发先决条件:** 07 本地接口、069 迁移与 catalog 翻译已集成复验，可开始依赖这些接口的开发和受控测试；依据见[执行记录](../execution.md#开发依赖与发布依赖)。
**发布依赖:** 07 全部验收（含真实媒体 LIVE）和本票完整清单仍须通过；本地开发不关闭外部缺口，也不删减真实索引覆盖要求。

## 验收清单

- [ ] 逐目录、逐页遍历所有可收录范围；上游搜索仅作补充或核对，不替代目录覆盖证据。
- [ ] 以预先列明合格集合的完整合成树验证收录、排除、分页变化及重复页；未登记内容不能被遗漏。
- [ ] 每批落盘检查点并释放资源，取消、失败、关闭重启及重试不丢失已完成进度或生成重复对象。
- [ ] 分别呈现分区、目录、条目、失败、访问限制与待确认空目录；未知分母不显示虚构百分比，失败或未完成范围不算完整覆盖。
- [ ] 扫描并发、每秒速率、单响应上限和低空间暂停按配置生效；已存内容仍可读、个人记录保留，暂停可恢复且不冒充完成。
- [ ] 记录真实运行的范围、时间、进度和失败情况；不上普通 CI 全站抓取，搜索命中数不作作品总量。

## 测试与交付边界

**测试入口:** H、R；进度入口按需要复用 F，真实覆盖用实际运行报告说明。

H 使用真实 HTTP 路由、会话与迁移 SQLite；R 实际关闭并重启同一应用；F 仅运行少量纯功能用例，关闭截图采集，不做截图、像素、布局或人工视觉验收。

遵守工单总览的[共同完成要求](../ticket-proposal.md#共同完成要求)，复用既有测试入口；不新增测试技术栈或安装授权。

本票验收证据须对应实际产物，相关文档同步并提交、推送 Git。工单发布不代表功能实施或生产授权。
