# 04: 编号作品全源个人评分与备注

**What to build:** 用户为已登记或未登记的远端编号作品保存、修改和清除个人评分备注，重开及切换来源后读取同一份记录。

**Blocked by:** None (can start immediately)

**Status:** resolved
**Implementation:** resolved；本地实现与 H/F 已验收；生产部署验收见 17。

编号作品的个人评价入口、必要登记、隔离、重启与浏览器功能验收完成，见[04 验收证据](../evidence/04-personal-reviews.md)。总流程继续由[执行记录](../execution.md)维护。

## 验收清单

- [x] 沿用已有评分取值和清除语义；未提交字段保持，显式清除仅影响指定字段。
- [x] 按现有权限登记未登记作品的必要信息，使其出现在作品库；不生成媒体下载任务或写入受管理音频。
- [x] 同一作品跨源共享当前用户记录，重开与重启后保持；个人记录与公共评分、元数据分别保存。
- [x] 两用户分别写入并交叉读写，只有本人能读取、更新或清除自己的记录；服务端验证权限。
- [x] 复用现有个人状态与登记流程，交付可实际操作的保存入口，不只增加数据库字段。
