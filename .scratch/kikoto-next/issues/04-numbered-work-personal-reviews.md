# 04: 编号作品全源个人评分与备注

**What to build:** 用户为已登记或未登记的远端编号作品保存、修改和清除个人评分备注，重开及切换来源后读取同一份记录。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**依据:** [正式规格](../spec.md) · [工单总览](../ticket-proposal.md)

## 验收范围

**主责:** AC-12、AC-13

**共同:** AC-28

AC-12 的编号作品场景及 AC-13 的基础隔离边界；新对象与新入口由对应后续票自验。

## 验收清单

- [ ] 沿用已有评分取值和清除语义；未提交字段保持，显式清除仅影响指定字段。
- [ ] 按现有权限登记未登记作品的必要信息，使其出现在作品库；不生成媒体下载任务或写入受管理音频。
- [ ] 同一作品跨源共享当前用户记录，重开与重启后保持；个人记录与公共评分、元数据分别保存。
- [ ] 两用户分别写入并交叉读写，只有本人能读取、更新或清除自己的记录；服务端验证权限。
- [ ] 复用现有个人状态与登记流程，交付可实际操作的保存入口，不只增加数据库字段。

## 测试与交付边界

**测试入口:** H、R；保存和字段清除入口复用 F。

H 使用真实 HTTP 路由、会话与迁移 SQLite；R 实际关闭并重启同一应用；F 仅运行少量纯功能用例，关闭截图采集，不做截图、像素、布局或人工视觉验收。

遵守工单总览的[共同完成要求](../ticket-proposal.md#共同完成要求)，复用既有测试入口；不新增测试技术栈或安装授权。
