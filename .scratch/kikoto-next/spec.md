## 已确认需求

### 内容翻译

- Q1：以自动翻译效果为准，可以复用其他成熟方案，不强制接入沉浸式翻译官方产品。
- 用户无需安装浏览器翻译插件；翻译与显示语言切换联动。
- Q5：翻译作品标题、简介、系统标签及目录显示名，包括后续动态加载的这些内容。
- Q11：可翻译内容默认只显示译文，提供查看原文入口。
- Q12：复用用户现有的 AI/翻译接口。
- Q23：选用 Index-Translate-35B-A3B，并提供自行配置能力；该选择不代表现有接口已支持或已验证此模型。
- Q26：管理员在 Kikoto 设置中统一配置翻译接口地址、API 密钥和模型名称，供所有用户使用；每位用户的显示语言仍独立。
- Q18：自动翻译当前浏览的可翻译内容，并复用已有译文缓存。
- Q20：译文等待或接口失败时先显示原文与翻译状态；成功后自动替换，失败提供重试入口。
- Q29：显示语言选择繁体中文时，先生成简体译文，再使用成熟的简繁转换规则生成繁体。
- 社团名称、声优名称、个人标签和用户备注保留原文，不送入自动翻译。
- 界面语言独立控制菜单、按钮、系统提示；内容翻译不改写界面语言设置。
- 显示名与作品、来源、版本、实际路径和播放位置的身份分离；译文不能成为定位真实文件的依据。

### 新网络源

- 目标为用户指定的 [OpenList 音声目录站](https://www.asmrgay.com/)。
- Q6、Q13：收录匿名可访问且可直接播放的全部音声，包含无 RJ 等发行编号的音声；跳过仅压缩包或仅字幕的目录。
- Q9：在 Kikoto 中提供统一作品卡片，搜索索引覆盖全部符合收录条件的音声，不以已经发现的条目作为搜索范围上限。
- 密码目录、维护中的目录及读取失败不能伪报为已完整索引；是否需要额外登录能力尚未提出。
- Q19：来源维护或扫描失败时，保留已索引的作品卡片，并标明相应来源暂不可用；保留个人评分和备注。
- Q24：首次索引完成后，每天启动一轮后台更新，低速执行并支持手动刷新；扫描未完成时继续推进并显示进度，不承诺每天完成全站扫描。
- Q27：后续完整扫描确认某作品的所有来源都已删除时，仍保留作品卡片和个人记录，标明无可用来源，由用户手动清理，不自动清理。
- 全量搜索索引指作品与来源的可检索信息，不等同于下载或镜像音频。尚未登记的来源索引条目也能搜索、展示卡片和浏览目录；登记不是收录前提。
- 该站与 Kikoeru 作品接口不同，适配优先使用 OpenList 标准目录能力与 Kikoto 既有来源能力边界。

### 无码音声的作品边界

- Q16：同一音声系列合成一张作品卡片，内部列出各个单集。
- Q17：系列和每个单集分别保存评分、备注；系列归组保留各集的独立身份。
- Q22：有明确系列名、集数或系列目录证据才自动归组；其余内容独立展示，并提供确认归组入口。
- MP3、FLAC 等音频格式及分轨子目录归属于对应内容，不各自生成作品卡片。

### 同一作品的多个来源

- 一个作品能够显示多个来源目录，并可选择要浏览、使用的来源。
- Q14：播放中点击其他来源标签，只切换浏览的来源目录，当前播放继续；点击所选来源的具体音轨后才切换播放。
- Q21：打开作品详情先显示已有来源结果，后台检查未知或过期来源，并提供手动刷新。
- 有可靠发行编号或既有作品关系时，优先复用已有作品关联。
- Q8、Q10：无发行编号的作品依据标题、声优等多项信息匹配；仅高置信且唯一的候选可自动关联，个人记录冲突遵循下节 Q15。
- 证据不足、出现多个候选或信息相互矛盾时，分别展示并提供用户确认入口。
- Q28：人工系列归组、作品关联和拆分属于全库共用资料，沿用现有资料编辑权限；任何个人评分或备注冲突只由记录本人处理，不向其他用户暴露记录。
- 相似关系不能直接证明不同版本具有相同音轨与时间轴；播放接续需要独立验证。

### 所有来源的评分和备注

- 所有来源的作品均能保存当前用户的个人评分和备注，包括尚未登记的远端作品和无发行编号作品。
- Q2：同一作品跨源共享该用户的一份评分和备注。
- Q15：同一用户在两条待关联作品上已有不同评分或备注时，保留两份记录并暂停合并，待记录本人确认评分和备注后完成关联；不得自动覆盖或拼接。不同用户之间的评价差异不构成此类冲突。
- Q25：误关联拆分时，合并后新增或修改的评分、备注由记录本人在拆分预览中选择归属，可选择两边保留；不得自动替本人决定或丢弃记录。
- Q7a：评分时允许自动登记必要作品信息并出现在 Kikoto 作品库列表；此操作不下载音频。
- 个人评分和备注与站点提供的公共评分、作品元数据分开；不同用户的记录互不覆盖。
- 作品库登记、来源目录跟踪、媒体下载和播放缓存是不同动作，不以评分隐式触发媒体下载。

## 已核实的实现起点

以下为官方基线的静态证据和接口只读核查结果，用于定位后续工作，不表示已复现用户报告：

- 显示语言与界面语言已有独立设置；现有内容语言选择主要选择已有多语言元数据，不能保证任意内容都有译文。
- 接口只读核查：现有网关运行且健康检查成功；当前官方 Kikoto 配置未发现翻译接入。所选模型在现有接口上的可用性、额度、协议端点及真实生成延迟仍未验证。
- 官方模型资料的服务示例使用 Index-Translate-35B-A3B，权重仓库为 IndexTeam/Index-Translate-35B-A3B-preview；实际接口调用的模型名称由管理员配置。官方资料列出中文、英文、日文和韩文，未单列繁体中文；Q29 明确转换方式，实际翻译与转换质量仍待验证。
- 多源目录已有标签和切换模型；可用性未知的来源可能被跳过目录加载，需要用具体作品复现。
- user_work_state 已有 rating、note，键为用户与作品；官方个人状态编辑接口尚未提供评分备注编辑字段。
- 远端作品现有个人状态流程会先跟踪作品以取得作品标识；评分接入需验证登记范围及不下载的要求。
- 既有作品身份主要依赖发行编号。无编号音声的纳入与自动关联需要明确扩展，不能伪造 RJ 编号。
- 系列目录已有 party_series 与 party_series_work，成员依赖作品编号；现有系列页逐成员显示卡片，未提供系列个人评分备注。参见[基线结构](../../backend/migrations/baseline/068_v0.8.3.sql)与[系列页面](../../frontend/src/pages/CirclesPage.tsx)。
- 现有个人数据导入导出以有效发行编号寻址，不能作为无码作品和系列记录已受支持的依据。
- 普通音轨选择从头播放，继续按钮或恢复当前队列读取保存进度；来源标签与普通点播的改动可以保留此规则，参见[前端播放约定](../../docs/architecture/frontend.md#interaction-principles)。
- OpenList 已观察到分区、创作者、作品与音频格式目录；不同分区不能假定有一致的作品边界。
- OpenList 通用行为参照[目录接口](https://github.com/OpenListTeam/OpenList/blob/main/server/handles/fsread.go)与[搜索实现](https://github.com/OpenListTeam/OpenList/blob/main/internal/search/search.go)：列表总数只对应当前目录，搜索依赖站点已有索引；目录响应不保证提供稳定身份，媒体链接也不保证永久有效或直接可播。本站部署版本尚未核实。
- 部署环境匿名根目录请求成功，随后额外 12 次元数据请求（10 次列表、1 次搜索、1 次文件信息）均返回 HTTP 200、API 200。根包含六个音声分区和更新日志；样例可下探到 MP3 目录并取得文件链接信息。本机直连重置和代理 HTTP 403 不代表部署环境访问失败。
- 样例分区的 MP3 搜索返回 22167 个索引命中，这不是作品总量，也不证明完整覆盖。两个分区顶层返回空目录，原因尚未核实；样例未提供可确认的稳定对象 ID 或内容哈希。尚未请求媒体 HEAD、媒体内容或实际播放，不能宣称 Range 播放及全量索引已验收。

## 已确认的设计方案

本节记录 Q31 确认的设计方案。资源参数作为可调整的初始默认值，以样例测量校准；实施状态仍为待开始。

### 内容翻译

- 复用现有显示语言偏好、对应语言元数据和服务端出站请求边界。优先使用当前作品与版本已有的对应语言字段，缺失时调用翻译；显示语言只改变展示文字，保留当前音声版本、选中来源与文件身份。
- 使用管理员配置的兼容接口，遵循 Index-Translate 的单条 user 消息翻译模板。翻译目标语言由内容设置映射；依据接口支持情况关闭推理输出，校验空结果、截断与格式错误。模型调用名、权重仓库名和 UI 展示名分别处理。
- 密钥仅由服务端保存和使用，配置读回掩码。源文字作为待翻译资料，译文按文本渲染；社团、声优及个人文字遵守已确认保护范围。
- 原文、目标语言、模型与模板版本共同区分译文缓存；模型或原文变化后不复用不匹配结果。同一请求去重，旧语言结果不会覆盖新选择。繁体转换优先复用成熟转换库，保持被保护的名称。
- 官方协议证据见[模型卡](https://huggingface.co/IndexTeam/Index-Translate-35B-A3B-preview)、[公共调用客户端](https://github.com/bilibili/Index-Translate/blob/main/inference/llm/call_api.py)及[语言清单附录](https://arxiv.org/html/2609.40181)。这些引用不把用户的接口自动改成官方公共服务。

### 来源索引、作品与系列

- 未登记的来源索引条目也能搜索、显示统一卡片和浏览目录；保存个人评价时才按需要登记作品信息。跟踪或登记不构成全量索引的收录前提。
- 复用现有作品、版本、外部标识与系列结构，补充无码内容所需的稳定内部标识和来源定位映射，保留已有编号作品的访问与关联行为。具体迁移和路由兼容步骤在实施计划中列出，发行编号不能被伪造。
- 系列是归组对象，各单集保留独立身份；系列和单集分别关联个人状态。已有编号和可靠版本关系优先，自动匹配遵循 Q8、Q10、Q15、Q22，不把系列成员并成同一录音。
- 目录改名或移动先尝试已知稳定标识及可靠来源证据；只能确认唯一同一对象时更新定位映射。证据不足保留原对象和记录，提供待确认候选，目录显示名或链接签名不作为永久身份。
- 复用 SQLite 检索能力与持久任务机制；来源适配依据能力与类型，复用出站传输、超时、响应上限及取消逻辑。索引保存可检索元数据，音频仍从所选来源播放。

### 索引更新与多源目录

- 以可恢复的目录队列逐目录、逐页遍历；完成一批就保存检查点并释放数据库与执行资源。相同来源已有扫描时复用或续跑，避免每日触发产生重叠全站任务。
- 分别显示分区状态、已扫描目录、已发现条目、失败与待确认空目录；分母未确定时不展示虚假的全站百分比。维护、权限限制、失败和未完成范围不会被计为完整覆盖。
- 上游搜索补充发现与核对，不能单独证明完整覆盖；只有成功完成相应范围的扫描，才能对该范围中未再出现的来源位置作缺失判断。缺失、维护和请求失败分别记录，卡片与个人记录按 Q19、Q27 保留。
- 来源详情先呈现缓存结果，后台刷新未知或过期来源，单个来源失败保留其他已知结果。继续复用全局播放器，普通音轨点播从头播放，通过继续按钮恢复进度；不因切换浏览标签猜测跨源音轨时间轴。

### 个人记录与共享操作

- 在已有作品个人状态接口上补齐评分与备注，并为系列添加独立个人状态；复用现有登记和权限边界，验证登记不会触发音频下载。数据导入导出覆盖新增评价对象，不能静默丢弃无码或系列记录。
- 冲突按同一用户在两个待关联对象上的同一字段判断；不同用户评分不同不构成冲突。两侧已有不同评分或备注时暂停，记录本人确认；空值与未填写信息不自动覆盖已有内容。
- 有资料编辑权限者发起共享关联或拆分。受影响用户只处理自己的评价，不需要额外资料编辑权；所有必要确认完成前保持待处理，未回应者的记录保留，其他用户只看到必要操作状态。
- 复用现有管理与预览交互，展示关联前后对象、来源归属和本人的记录选择。操作提交前复核相关数据是否变化，过期预览需刷新；保存结果与记录归属保持一致，保留撤销或拆分所需依据。
- 手动清理受资料权限限制，不能替他人删除个人记录。评价对象仍被个人记录引用时，延后共享对象的物理删除，保留可寻址记录。

### 初始资源预算

| 范围 | 初始默认值与边界 |
| --- | --- |
| 翻译请求 | 全局并发 1，待处理队列最多 32 项，单次请求上限 60 秒；取消不再需要的排队任务，超时不自动反复重发。 |
| 译文缓存 | 磁盘上限 256 MiB，只淘汰可重建译文；个人记录和来源身份不属于可淘汰缓存。 |
| 目录扫描 | 并发 1，每秒最多 1 次元数据请求，每次响应最多 2 MiB；分批落盘并保存恢复位置。 |
| 磁盘余量 | 可用空间低于 2 GiB 时暂停新增索引与缓存并提示，保留已有读取和记录；暂停不能显示为索引完成。 |

这些值通过管理员配置调整，并在真实样例测量后校准。费用和吞吐受所配置接口的额度与计费规则影响；本方案不新增模型托管或付费计划。

### 实施顺序与验证缺口

1. 在隔离开发环境固定基线，复现多源目录问题；先验证所配置 Index 接口和匿名来源的一条完整读取链路，建立真实样例与合成回归样例。
2. 完成翻译配置与显示、现有编号作品的评分备注、多源目录修复；每个独立修改携带文档、必要行为验证和 Git 提交。
3. 完成无码身份与系列成员兼容、全量来源索引、系列个人记录及共享确认/拆分流程，再做跨功能整合验证。
4. 复核新增迁移、个人数据导入导出、资源限制与恢复流程；构建及验收通过后再形成可审阅的部署与回退步骤，生产变更单独决定。

Q30：验收样例由实施方选择。尚需实际验证的事实包括模型端点及扩展参数兼容性、翻译和繁体转换质量、媒体 Range 与拖动播放、分页变化与完整覆盖、无码跨源匹配、改名/失联/恢复以及负载下的内存和请求成本。静态源码、元数据请求成功和模型健康检查均不能代替这些验收。

## 验收方向

- 内容语言和界面语言互不改写；迟到的旧语言响应不能覆盖当前选择。
- 可翻译字段在首次和动态加载时一致，译文可用后默认只显示译文且可查看原文；等待或失败时显示原文和状态，成功自动替换，失败可重试；名称与个人文字保持约定。
- 核实用户现有 AI/翻译接口后，用所选 Index-Translate-35B-A3B 实际验证约定内容的翻译；健康检查成功不能代替模型可用性与实际翻译验收。
- 管理员可在 Kikoto 设置中保存翻译接口地址、API 密钥和模型名称，重开及重启后仍生效，所有用户使用统一配置；无管理权限的用户不能修改该配置或取得 API 密钥，各用户的显示语言及界面语言保持各自约定。
- 自动翻译随当前浏览内容触发，重复访问复用匹配的译文缓存；目标语言或原文变化时，不显示不匹配的缓存译文。
- 繁体中文展示由简体译文经成熟转换规则生成；转换保持受保护名称、个人文字及真实路径身份，简繁缓存和展示不会混用。
- 多源属于同一作品，但目录、版本和真实播放路径保持来源身份；先显示已有来源结果，未知或过期来源在后台检查且可手动刷新；切换来源标签不打断当前播放，点击具体音轨后才切换播放。
- 全部匿名可访问且可直接播放的音声可在索引完成后检索，包含无发行编号内容；仅压缩包或仅字幕目录不进入可播放作品范围，失败和未完成范围明确可见。
- 首次索引完成后每天启动一轮低速后台更新，手动刷新可触发更新；未完成的扫描继续推进并显示进度，不能把每日启动或局部成功显示为全站扫描完成。
- 无码音声同一系列只有一张作品卡片，内部列出各集；音频格式及分轨子目录归对应内容。自动归组有明确系列证据，证据不足时独立展示并可人工确认。
- 系列与每个单集的评分、备注独立保存、重开可读，互不覆盖；同一评价对象跨来源共享当前用户的记录。
- 来源维护或扫描失败时，已索引卡片与个人记录保留，受影响来源显示暂不可用；其他来源的可用状态保持独立。
- 后续完整扫描确认作品的所有来源均已删除后，卡片和个人记录仍保留且重开可读，显示无可用来源；未完成或失败的扫描不能触发自动清理。手动清理不能级联删除他人的记录，仍有个人记录引用时延后共享对象物理删除。
- 全来源评分备注可保存、重开可读、跨源一致、用户隔离；评分不会触发音频下载。
- 同一用户在待关联作品上存在不同评分或备注时，两份记录保留且合并暂停；所有必要的本人确认完成后才提交关联。不同用户的不同评价不触发冲突，无自动覆盖或拼接。
- 误关联拆分预览中，记录本人可为合并后新增或修改的评分、备注选择归属或两边保留；拆分结果按本人选择持久保存，未选择的记录不被自动分配或丢弃。
- 人工系列归组、作品关联和拆分按现有资料编辑权限授权，保存后全库共用且重开可读；资料编辑权限不允许代替他人处理个人记录冲突，预览及结果不向其他用户暴露个人评分和备注。
- 索引与翻译请求有上限、可恢复且不阻塞既有播放；以当前产物完成相应验证后再宣称完成。
